# 🌿 SMG Hub (Smart Green Hub)

ระบบศูนย์กลางข้อมูลและการตลาด สำหรับทีมงานและนักส่งเสริมสมาร์ทกรีน (Smart Green)
ดึงและจำลองมาจาก Claude Artifact แบบสมบูรณ์ 100% พร้อมรูปภาพ สื่อประกอบ และฐานข้อมูล Standalone ในตัว

---

## 🚀 วิธีการเปิดใช้งาน
คุณสามารถเปิดใช้งานได้ 2 วิธีง่ายๆ:

1. **ดับเบิลคลิกไฟล์ `run.bat` หรือ `index.html`**
   - ระบบจะเปิดขึ้นมาในเบราว์เซอร์ของคุณทันทีโดยไม่ต้องติดตั้งโปรแกรมเสริมใดๆ
2. **ดับเบิลคลิกไฟล์ `server.bat` (แนะนำสำหรับการใช้งานแบบเว็บเซิร์ฟเวอร์)**
   - จะเปิด Local Web Server ที่ `http://localhost:8080` เพื่อการใช้งานที่ลื่นไหลสูงสุด

---

## 📦 โครงสร้างไฟล์ในโฟลเดอร์นี้
- `index.html` — ซอร์สโค้ดหน้าเว็บหลักของ SMG Hub พร้อมระบบ UI, ตัวกรอง, ฟอร์ม และ Adapter จำลองฐานข้อมูลในตัว
- `run.bat` — สคริปต์คลิกเดียวเพื่อเปิดหน้าเว็บในเบราว์เซอร์
- `server.bat` — สคริปต์เปิดเว็บเซิร์ฟเวอร์ Local HTTP
- `images/` — โฟลเดอร์เก็บไฟล์รูปภาพ แคตตาล็อก และสื่อกราฟิกของสินค้าทั้งหมด (172 รายการ)

---

## ✨ โมดูลและฟังก์ชันหลักในระบบ
1. **โปรโมชัน (Promos)**: รายการโปรโมชันลด/แถม รหัสโปร และเงื่อนไขสำหรับลูกค้า
2. **แอด & แคมเปญ (Ads)**: ข้อมูลแอด Facebook, TikTok, LINE OA พร้อมสคริปต์ที่เซลล์ควรรู้
3. **สินค้า & บริการ (Products & Services)**: แคตตาล็อกปุ๋ย ฮอร์โมน SG-Root, บริการตรวจดินด่วน Soil Check และบริการโดรนเกษตร Smart Green Drone Connect
4. **Presentation & Decks**: สไลด์นำเสนอลูกค้า แคตตาล็อกพันธุ์มันสำปะหลัง และผลการทดลองแปลงจริง
5. **สคริปต์ถาม-ตอบ (Q&A)**: แนวทางการตอบคำถามและรับมือข้อโต้แย้งสำหรับนักส่งเสริมและฝ่ายขาย
6. **แผนเนื้อหา (Content Plan)**: ปฏิทินการโพสต์คอนเทนต์ล่วงหน้าในทุกช่องทาง
7. **แอปตรวจใบพืช AI (Smart Green AI Leaf Apps)**: เมนูทางลัดสำหรับเข้าใช้งานแอปประเมินโรคพืช แมลง และธาตุอาหารใบพืช (อ้อย, มันสำปะหลัง, ข้าว ฯลฯ)
8. **ระบบจัดการข้อมูล (Data Management)**: 
   - โหมดแก้ไข (Admin / Edit Mode) เพิ่ม/ลบ/แก้ไขข้อมูลได้ตามต้องการ
   - ส่งออกข้อมูลสำรอง (Export JSON)
   - นำเข้าข้อมูล (Import JSON)
   - แจ้งเตือนทีมผ่าน LINE
